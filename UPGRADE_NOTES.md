# UPGRADE NOTES

## Текущий релиз

Бот подготовлен как персональный Telegram-помощник для ежедневного использования: заметки, напоминания, кнопочное управление, восстановление ожидающих задач после рестарта и постоянный запуск на Linux VPS.

## Что изменилось

- доступ открыт для всех пользователей; непустой `BOT_ALLOWED_USER_IDS` при необходимости включает allowlist;
- секреты исключены из Docker-контекста, Git и новых логов;
- UX-журнал обезличен и содержит только метаданные действий;
- напоминание получает один повтор доставки через 10 минут без реакции;
- заметки, напоминания, архивы и поиск открываются через интерактивные карточки с пагинацией;
- импорт JSON валидируется заранее и применяется одной SQLite-транзакцией;
- экспорт JSON не содержит `chat_id` и не обрезает данные молча;
- SQLite-миграции остаются добавочными и совместимыми со старой базой;
- локальные и VPS-backup-снимки создаются через SQLite online backup API и атомарно заменяются только после проверки;
- добавлены Docker Compose, VPS preflight, healthcheck, restic backup и проверка восстановления.

## Перед обновлением VPS

```bash
cd /opt/telegram-assistant
deploy/backup_to_s3.sh
git pull
deploy/preflight.sh
docker compose up -d --build
docker compose exec -T bot python tools/healthcheck.py --db /data/notes.db
```
