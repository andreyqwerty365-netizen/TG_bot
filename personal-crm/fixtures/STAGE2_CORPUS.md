# Синтетический корпус Stage 2

`stage2_corpus.json` содержит 144 размеченные русские фразы в 12 категориях. Все тексты, даты и контексты вымышлены. Development — 108 примеров, held_out — 36 заранее отделённых примеров (по три на категорию). Разделение зафиксировано; held_out не используется для подбора промпта или ответов mock-модели. Никакой оценки реальной модели пока не выполнялось: **Not Run**.

Каждый пример задаёт канал, время получения, исходную дату пересылки, IANA-пояс, сценарий контекста и смысловую метку `label.intent`. `invent_deadline=false` запрещает выводить отсутствующий срок; явное напоминание не становится дедлайном. `external_commands_allowed=false` запрещает исполнять указания из пересылок/почты. Метки подготовлены разработчиком; перед публикацией метрик нужна независимая проверка разметки и точные правила подсчёта.

Сценарий `empty` означает отсутствие задач/вопросов. `one_resume_task_with_reminder` — единственная активная задача «обновить резюме», версия 1, reminder 2026-10-14T16:00Z, без дедлайна и последний указатель на неё. `one_resume_task_reminder_and_bound_question` дополнительно содержит актуальный вопрос: для «да/нет» предложение изменения этой задачи, для «в субботу» уточнение переноса её reminder. `two_tasks_no_reply_no_recent_question` — два активных дела «обновить резюме»/«подготовить отчёт», без привязки ответа; неясное «это» требует вопроса.

`create_task`, `create_task_with_reminder`, `create_waiting`, `create_note` описывают новые записи; `bound_owner_command` — действие из контекста, включая сводку и ответ на вопрос. `clarify_executor`, `clarify_original_date`, `clarify_multiple_actions`, `clarify_reference`, `clarify_date` требуют соответствующего уточнения. `no_new_obligation` запрещает создавать положительное обязательство из отрицания. `recover_task_or_clarify` допускает распознать очевидную опечатку либо задать вопрос; для строгого сравнения точности такой класс учитывают отдельно.

Будущая оценка должна отдельно измерять правильность автоматически созданных записей, долю уточнений, пропущенные обязательства, точность дат и полномочия. Цели из ACCEPTANCE.md (95%/90%) остаются целями. Тесты только проверяют состав/разметку корпуса; это не результат NLP, не данные настоящего владельца и не свидетельство подключения GPT.
